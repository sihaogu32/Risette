# Risette v1.0.0 — pi extension package → 獨立 npm CLI（spec）

Status: in-progress（refactor branch `refactor/v1.0.0-cli`）

把 `/home/sihaogu/pi/Risette/` 從 v0.2.0 的「pi extension package」（需先裝 pi、再 `pi install` Risette、再 `pi install` pi-subagents、再 vendor playwright-cli skill）翻成 v1.0.0 的獨立 npm CLI：使用者 `npm install -g risette@latest` 後直接 `risette` 進入帶完整擴充的 agent。

## 事實基礎

- pi-coding-agent 0.70.5 在 `dist/main.d.ts` 公開 `main(args, options?: { extensionFactories?: ExtensionFactory[] })`，外掛程式化注入由此通道完成（npm public API，符合 extension_map 引用規範）。
- pi-coding-agent 公開 `ExtensionAPI` / `ExtensionFactory` 等 type；既有 3 個 extension（`extensions/{permission-gate,protected-paths,financial-news}.ts`）已符合 `(pi: ExtensionAPI) => void` 簽名，搬到 `src/extensions/` 後零修改即可被 `extensionFactories` 收進。
- pi 標準 npm pi-package 載入靠 `~/.pi/agent/settings.json` 的 `packages: ["npm:<pkg>"]` 機制 + 套件根的 `pi` 欄位 manifest（見 docs/packages.md）。
- `pi-subagents@0.24.0` 是純 manifest pi-package（npm tarball 含 raw `src/*.ts` + `agents/*.md` + `prompts/*.md` + `skills/pi-subagents/SKILL.md`，無 dist/、無 programmatic export），靠 pi 自家 package loader 載入。

## 整體架構

Risette v1.0.0 = 單一 npm package，包一層 `pi.main({ extensionFactories })` 的薄 CLI。

- `bin/risette.mjs`（薄 launcher，純 JS）→ `dist/entry.js`（`import { main } from "@mariozechner/pi-coding-agent"`）。
- pi-mono 4 套件以 `dependencies`（caret `^0.70.5`）鎖；CLI 自帶 runtime，不再要求使用者先裝 pi。
- 3 個 extension 用 `git mv` 從 `extensions/` 搬到 `src/extensions/`，由 `src/extensions/index.ts` 收成 `ExtensionFactory[]`。
- `pi-subagents` 走 pi 原生 package loader：列在 `dependencies`，postinstall 把 `"npm:pi-subagents"` idempotent 寫入 `~/.pi/agent/settings.json` 的 `packages` 陣列（不繞開 `main()`、不自製 ResourceLoader）。
- `playwright-cli` skill vendor 進 `skills/playwright-cli/`；postinstall idempotent 複製到 `~/.pi/agent/skills/playwright-cli/`，再 best-effort 跑 `npx playwright install chromium`。
- 不做 OpenClaw 的 plugin-sdk facade、pi-embedded-runner、pi-hooks、pnpm workspace、自定 manifest（見 §不做清單）。

## package.json（v1.0.0）

關鍵欄位：

- `name: risette`、`version: 1.0.0`、`type: module`、`engines.node >=22.12`。
- `bin: { risette: "bin/risette.mjs" }`。
- `main: ./dist/entry.js`、`exports.": { types, import }`。
- `files: ["bin/", "dist/", "skills/", "scripts/", "AGENTS.md", "README.md", "LICENSE"]`。
- `dependencies`：`@mariozechner/pi-coding-agent ^0.70.5` + `@mariozechner/pi-ai ^0.70.5` + `@mariozechner/pi-tui ^0.70.5` + `@mariozechner/pi-agent-core ^0.70.5` + `pi-subagents ^0.24.0` + `typebox ^0.34.0`。
- `devDependencies`：`typescript ^5.6.0`、`@types/node ^22.0.0`。
- `scripts`：`build`、`dev`、`typecheck`、`clean`、`start`、`prepublishOnly`、`postinstall: "node scripts/postinstall.mjs || true"`。
- `pi: { extensions: ["./dist/extensions"] }` 留作向後相容（成本零，給「萬一有人用 `pi install npm:risette`」用）。

選擇 `dependencies` 而非 `peerDependencies` 的理由：CLI 自帶 runtime，使用者不需另裝 pi；caret 容忍 patch、不接受 breaking minor。

## CLI 入口三層

### bin/risette.mjs

純 JS（~30 行）：檢查 Node 版本 >= 22 → `await import("../dist/entry.js")` → 缺 dist 時印明確錯誤訊息。**不做** OpenClaw 的 compile-cache respawn / source-checkout detection。

### src/entry.ts

```ts
#!/usr/bin/env node
import { main } from "@mariozechner/pi-coding-agent";
import { extensionFactories } from "./extensions/index.js";

await main(process.argv.slice(2), { extensionFactories });
```

### src/extensions/index.ts

```ts
import type { ExtensionFactory } from "@mariozechner/pi-coding-agent";
import permissionGate from "./permission-gate.js";
import protectedPaths from "./protected-paths.js";
import financialNews  from "./financial-news.js";

export const extensionFactories: ExtensionFactory[] = [
    permissionGate,
    protectedPaths,
    financialNews,
];
```

3 個 extension `git mv` 後零修改，原先 `import type { ExtensionAPI } from "@mariozechner/pi-coding-agent"` 與 `export default function (pi)` 簽名都對得起來。

### pi-subagents 載入策略

`pi-subagents` 走 pi 標準 package loader（npm pi-package manifest 模式），**不**透過 `extensionFactories` 程式化注入。理由：

- pi-subagents@0.24.0 是純 manifest pi-package，無 programmatic export 可注入。
- 透過 `main()` + `extensionFactories` 唯一通路無法直接 hand-off 一整個 npm pi-package；要繞開 `main()` 自製 `DefaultResourceLoader({ additionalExtensionPaths })` + `AgentSessionRuntime` + `InteractiveMode` 才能塞，違反「不做 OpenClaw 規模 wrapper」原則。
- pi 原生 `packages: ["npm:pi-subagents"]` 機制成熟、會跟著 `pi update` 升級。

實作：

- `package.json.dependencies` 列 `pi-subagents ^0.24.0`，使用者 `npm install -g risette` 時 npm 順手裝好（在 risette 自己的 `node_modules/`）。
- `scripts/postinstall.mjs` idempotent 把 `"npm:pi-subagents"` 補進 `~/.pi/agent/settings.json` 的 `packages` 陣列（已存在就 skip）。
- pi 啟動掃 `~/.pi/agent/settings.json` → 看到 `npm:pi-subagents` → 從 `~/.pi/agent/npm/pi-subagents/`（pi 自管，由 pi update 維護）載 manifest。risette 自己 `node_modules/pi-subagents/` 與 pi 那份是兩個獨立副本——這對 pi-subagents 沒影響（沒 hot path 共享 module instance），但表示 risette 的 dependencies 列出 pi-subagents 主要意義是「強烈聲明它是 risette 的一部分」與「離線時也能 fallback」，不是運作必要。

## Skills + chromium（postinstall 全自動）

### skills/playwright-cli/ 同步流程

vendor 自 `playwright-cli install --skills` 的輸出。AGENTS.md 寫死同步指令；保留上游 LICENSE/NOTICE。

```bash
tmp=$(mktemp -d) && (cd "$tmp" && playwright-cli install --skills) && \
  rm -rf skills/playwright-cli && \
  cp -r "$tmp/.claude/skills/playwright-cli" skills/playwright-cli
git add skills/playwright-cli && git commit -m "skills: resync playwright-cli (upstream <date>)"
```

### scripts/postinstall.mjs

職責（皆 idempotent；`RISETTE_SKIP_POSTINSTALL=1` 與 `CI=true` 全跳過）：

1. 把 `skills/playwright-cli/` copy 到 `~/.pi/agent/skills/playwright-cli/`（已存在則 skip，不覆寫使用者自改版）。
2. 把 `"npm:pi-subagents"` 補進 `~/.pi/agent/settings.json` 的 `packages` 陣列（已存在則 skip）；settings.json 不存在則建空骨架。
3. Best-effort 跑 `npx playwright install chromium`；失敗（離線/無權限）只印警告、不擋 install。

`postinstall` 在 npm script 用 `node scripts/postinstall.mjs || true`，雙重防呆：script 內也自處例外。

## Release 流程

1. `main` → `refactor/v1.0.0-cli` → 完整重構 → PR → merge。
2. 在 v0.2.0 commit (`27f32fc` 或 `e005775`) 補打 `git tag v0.2.0-frozen`。

4. `npm whoami` 確認 → `npm publish --access public`。
5. `npm view risette` 驗 v1.0.0 上架；本機 `npm install -g risette@latest` 跑端到端驗收。

## 不做清單（避免誤學 OpenClaw）

1. 不做 `packages/plugin-sdk` facade — 3 個 extension 在同一 src 樹內、無外部 plugin 來源；facade 只在多 plugin 來源契約時有價值。
2. 不做 `pi-embedded-runner` / `pi-hooks` — pi 已透過 `main({ extensionFactories })` 公開 wrapper 路徑；OpenClaw 那層是它自家「gateway-as-host」拓撲下的特殊需求。
3. 不轉 pnpm workspace、不切 `packages/*` — 單包夠用；達 5+ extension 且依賴互斥才再評估。
4. 不自定 plugin manifest（不做 `*.plugin.json`）— pi 標準的 `ExtensionFactory` callback array 就足夠程式化註冊。
5. 不 vendor pi-mono 程式碼 / 不放 git submodule — 用 npm `dependencies` + caret 範圍，dedupe 由 npm 處理。
6. v1.0.0 不加 vitest / playwright-test / eslint — 3 個 extension 可手 review；加測試框架等到行為改動會引入 regression 時再說。
7. 不在 `bin/risette.mjs` 做 compile-cache respawn dance — 啟動 <300ms、不需要 OpenClaw 那層 200 行 launcher。
8. 不 override pi 預設 extension discovery — 使用者放在 `~/.pi/agent/extensions/` 的個人擴充仍會被 pi 載入並與 Risette 內建合併，這是 feature 不是 bug。
